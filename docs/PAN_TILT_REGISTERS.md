# pan_tilt_ctrl AXI-Lite 寄存器表 v1.0

32位、4字节对齐、4K空间。地址由新BSP宏生成，本轮为0x43C20000。RW支持WSTRB，未定义/未对齐/只读写入/非法约束写入SLVERR。RO为只读，W1为写bit0=1且WSTRB[0]=1触发。

| 偏移 | 类型 | 复位值 | 内容 |
|---|---|---|---|
| 00 | RO | 50544C54 | ID（PTLT） |
| 04 | RO | 00010000 | 版本1.0 |
| 08 | RW | 0 | 请求使能 bit0 yaw、bit1 pitch |
| 0C / 10 | RW | 1500 | yaw / pitch影子脉宽，低16位，单位μs |
| 14 / 18 | RO | 1500 | 两轴实际生效脉宽μs |
| 1C / 20 | RW | 1400 / 1600 | yaw最小/最大μs |
| 24 / 28 | RW | 1400 / 1600 | pitch最小/最大μs |
| 2C / 30 | RW | 1500 | 两轴配置中心μs（仅保存，不自动运动） |
| 34 | W1/RO | 0 | 统一提交；读bit0表示排队或提交传递中的pending |
| 38 | RO | 0 | bit0/1周期边界使能；bit8待提交（关闭请求立即清除输出） |
| 3C | RO | 0 | 已生效统一提交计数，32位自然回绕 |

限位允许500..2500μs且min<=max；中心必须在当前限位内。初始1400..1600μs用于首次小范围测试。影子寄存器可写超界数值，在统一提交时由硬件夹紧；软件同时按已配置限位约束。

快照字段在下一次W1前保持不变。frame_error先清最新valid，再在下一次快照中反映；历史PS快照不会异步改变。与W1同周期的结果/异常也锁存到该次快照。有效目标需 `(flags & 7)==5`。

命令邮箱pending期间禁止覆盖命令字/请求序号。C调用与UART相同的命令解析器后先写结果/状态再ACK；ACK后才能再次填命令。快照与命令邮箱是不同锁存域，JTAG不能直接触发视频快照以免与应用并发冲突。

PWM监测不保证多寄存器快照一致性，只用于稳定脉宽下的诊断。禁用中途的高电平会测得截短宽度，重新启用后的第一个周期间隔包含关闭时间；第二个完整周期后恢复20ms。计数32位自然回绕。它测量的是内部输出网，不是物理引脚电压。

hold原因：0正常、1手动、2未双轴使能、3目标/帧异常、4过期/停帧、5尺寸/摄像头不匹配、6恢复追踪时间基准。
