## PID的实际状态

- 控制器输出脉宽变化率，再积分为位置；Kp单位us/(pixel·s)，Ki单位us/(pixel·s²)，Kd单位us/pixel。
- 已验收现场配置为 **PD：Kp=0.7、Kd=0.03、Ki=0、微分滤波tau=100ms**。用户确认小幅移动、换向、停稳正常，无明显来回摆动；失目标保持、遮挡恢复及模式切换正常。
- 非零Ki的计算、限幅、抗饱和和命令配置已经实现并测试；尚未完成非零Ki机械跟随验收。未定量比较P与PD的超调量、收敛时间和稳态误差，不能将可用性验收解释成PD性能必然更好。
- 默认重新下载仍为P/manual/PWM关闭；运行参数易失，需要执行恢复脚本。

## 运行与回退

在仓库根目录PowerShell中执行（串口号按设备管理器调整）：

```powershell
./scripts/download_visual_pid.ps1
# 恢复已标定配置；默认PWM关闭
./scripts/restore_visual_pid.ps1 -Port COM5
# 确认姿态与目标后才启用自动；此入口会设置中心
./scripts/restore_visual_pid.ps1 -Port COM5 -EnableAuto
# 回退上一平滑程序，启动仍为manual/PWM关闭
./scripts/download_visual_pid.ps1 -Rollback
```

正常已标定范围：yaw1100～1650us、pitch1240～1800us；方向yaw−1、pitch+1。用户后来选择的500～2500us宽范围实验另由`-WideExperiment`显式恢复，不属于全段机械标定。详细命令、参数、全新软件目录构建方法见[VISUAL_PID.md](VISUAL_PID.md)。

bit/XSA/ELF和完整BSP保留在本机独立build目录，未纳入Git；GitHub交付源码、测试、脚本和证据。从全新克隆复现时需先按前序集成流程生成匹配硬件，不能只执行依赖本机build产物的下载命令。

## 当前不足与下一步

1. 仍受光照、蓝色物体相接、严重侧视及遮挡影响；应补充多背景、多距离、双目标现场测试并统计漏检/误锁。

3. 曾出现源视频异常或冻结；已有异常保持保护，但尚未根治所有间歇性输入异常，需做长时间运行与错误计数分析。
4. 下一阶段适合记录同步目标误差/脉宽轨迹，定量对比P、PD，再决定是否启用小Ki；当前没有必须增加积分的现场证据。
